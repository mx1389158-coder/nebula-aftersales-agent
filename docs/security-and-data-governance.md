# 安全与数据治理

## 数据边界

当前数据集、账号、设备和工单均为虚构数据。日本区 Langfuse 只允许接收这些合成评测数据；在完成法务评估、跨境授权、数据处理协议和脱敏验证前，不得发送真实客户姓名、联系方式、序列号、对话或工单内容。

生产环境应关闭 `DEMO_MODE`，使用独立随机密钥、HTTPS 反向代理、最小权限数据库账号和受控 CORS。接口具备账号密码登录、JWT、tenant/user 硬隔离、Redis/本地限流与写工具确认门禁。

## 观测脱敏

Langfuse 记录模型、检索与时延元数据，真实环境接入前必须在观测入口增加企业认可的字段级脱敏。公开演示只使用合成数据。密钥仅通过环境变量注入，不写入日志、文档、评测报告和 Git。

## 保留与删除

长期记忆含同意状态、来源、置信度、有效期、替代关系和软删除；用户可查看、编辑和删除。审计记录保留治理操作但不复制敏感正文。数据库备份的保留周期和删除 SLA 应由部署方依据所在地法规配置。

## 工具边界

退款、换货、拆机、高压操作、真实硬件控制以及疑似冒烟/漏电均不得无人值守执行。工单创建必须二次确认并使用幂等键；企业 CRM 未接入时，本项目数据库是正式闭环后端。
