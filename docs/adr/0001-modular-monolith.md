# ADR-0001：先采用模块化单体与可替换端口

状态：已接受

## 决策

首版采用 FastAPI 模块化单体、独立 Worker 和 Vue 单页应用。生成模型、向量化、检索、记忆、工具与评测均通过小型接口隔离，不在业务路由中直接绑定 Ollama、Mem0、OpenViking 或 LightRAG。

## 原因

- 单机 8GB 显存和 32GB 内存不适合同时常驻多个重型服务。
- 版本过滤、用户隔离、写操作确认等业务规则必须由本项目掌握，不能委托给外部框架默认行为。
- 先以本地确定性实现形成可测试基线，再逐项接入参考项目，才能做有效消融。

## 后果

- 默认 SQLite + 哈希向量无需外部服务即可开发和测试。
- Compose 环境切换 PostgreSQL/pgvector，并保留 Redis 与本地模型接口。
- OpenViking、Mem0、LightRAG 和 Langfuse 作为适配器或实验方案接入，不是核心业务的硬依赖。
