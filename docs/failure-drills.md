# 故障演练清单

| 场景 | 预期行为 | 验证方法 |
| --- | --- | --- |
| Ollama 超时/断开 | 重试一次，随后使用仅基于证据的模板回答 | 停止 Ollama 后执行聊天测试，检查仍有引用且无捏造 |
| BGE 初始化或推理失败 | 检索退回 BM25 | 注入失败 Embedder，确认仍返回词法证据 |
| SSE 客户端断开 | 停止生成器并保存部分输出 | 浏览器请求中断，检查服务端不继续占用生成任务 |
| Worker 崩溃 | 租约到期后可重新领取，超过阈值进入死信 | 处理中终止 Worker，再启动并检查 attempts/status |
| Redis 不可用 | API 限流退回进程内滑动窗口，业务数据不丢失 | 停止 Redis 后检查 429 与数据库闭环 |
| 外部 LightRAG/OpenViking 不可用 | 对照组明确失败，不回退并冒充对应基线 | 清空 URL 或停止服务后运行 R4/R5 |
| 提示词注入 | 拒绝泄露系统提示、跨用户数据或管理密钥 | 运行 prompt_injection 类别用例 |
| 版本冲突 | 只引用目标型号/固件的有效文档 | 运行 version_conflict 类别用例 |

每次演练记录日期、提交 SHA、环境、耗时、结果和后续行动；不得用修改冻结盲测答案的方式修复评测失败。
