# 10 分钟验收演示脚本

1. **0:00–1:00 环境**：展示健康检查、真实登录和版本信息。
2. **1:00–3:00 版本化问答**：选择设备，询问当前固件问题，展示引用、版本过滤和决策轨迹。
3. **3:00–4:00 安全拒绝**：输入提示词注入与冒烟/漏电请求，展示拒绝或人工转接。
4. **4:00–5:30 记忆治理**：新增偏好，查看来源/有效期，编辑后删除，说明 tenant/user 隔离。
5. **5:30–7:00 工单闭环**：先触发 `need_confirm`，确认后创建工单，再用相同幂等键验证不重复创建。
6. **7:00–8:00 知识治理**：展示文档导入任务、版本发布/归档与回滚入口。
7. **8:00–9:00 技能治理**：展示候选技能、测试报告、审批、灰度和回滚。
8. **9:00–10:00 评测证据**：展示冻结数据哈希、Git SHA、类别指标、p95、Badcase 和浏览器 E2E 结果。

录屏时只使用合成数据，不展示 `.env`、密钥、数据库连接串或本机个人目录。
